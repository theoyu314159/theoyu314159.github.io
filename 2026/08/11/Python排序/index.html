2.selection sort:大概就是從後面開始一直挑最小的數字擺到前面去:

3.insertion sort:拿下一個數字並插入適當的位置:

data = [1, 6, 3, 2]
for i in range(1, len(data)):
    for j in range(i-1, -1, -1):
        if data[i] > data[j]:
            x = data.pop(i)
            data.insert(j+1, x)
            break
        if j == 0:
            x = data.pop(i)
            data.insert(0, x)

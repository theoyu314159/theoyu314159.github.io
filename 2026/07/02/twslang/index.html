twslang

新世代用語翻譯工具

https://pypi.org/project/twslang/0.1.1/

what’s this

這是一個能將新世代網路用語自動翻譯成白話文的工具，
例:很頂->非常棒

how to use

import twslang
twslang.render(句子)
簡單易懂吧~
